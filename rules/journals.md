# Journal Requirements

Nature's guidance governs the structure of every figure this skill draws: size, panel layout, which text goes on the figure and which in the caption, type, line weights and file format. It supersedes Tufte and the other journals listed here wherever they differ (`SKILL.md`, Part III). Tufte still governs style.

**Terms.** Nature calls the text printed under a figure the "figure legend"; this skill calls it the **caption**. The element inside a figure that explains its symbols or colors is the **key** (what plotting libraries call the legend). Quotes below keep Nature's word.

Requirements quoted from the journals' author guidelines, read on 16 November 2026. Journals revise these pages; when Nature's current guide differs from this file, Nature's guide wins.

## Nature

Sources: Nature, "Formatting guide" and "Final submission"; Nature Research figure guide, "Preparing figures – our specifications", "Building and exporting figure panels" and "Extended Data formatting guidelines" (URLs in `rules/references.md`).

### Size, type and files

| Requirement | Nature's words or values |
|---|---|
| Widths | "89 mm (single column)", "183 mm (double column)" (figure guide); "a column-and-a-half where necessary (120–136 mm)" (final submission). The formatting guide rounds these to 90 and 180 mm |
| Height | "The maximum height for a Nature figure is 170 mm, to allow space for the figure legend to fit underneath" |
| Size | submit "at the smallest appropriate size"; Nature may reduce figures further |
| Typeface | "a sans-serif typeface, preferably Helvetica or Arial, the same font throughout all figures in the paper" |
| Text size | "Maximum text size: 7pt"; "Minimum text size: 5pt" |
| Text color | "Avoid coloured text"; contrast above 4.5:1; colored text is recoloured black or white unless color is necessary for clarity or scientific meaning |
| Case | lettering "in lower-case type", first letter capitalized, no full stop |
| Numbers and units | a single space between number and unit; thousands separated by commas (1,000) |
| Text placement | avoid type over shaded or textured areas, and reversed type where possible |
| Scale | "Scale bars should be used rather than magnification factors" |
| Panel letters | "8 pt bold, upright (not italic) a, b, c" |
| Line weights | "between 0.25 and 1 pt at the final size" |
| Main-figure formats | vector `.ai`, `.eps` or `.pdf` with editable layers; fonts embedded (TrueType 2 or 42), not outlined; "Please do not rasterize line art or text"; JPEG, TIFF and PNG not accepted; under 50 MB |
| Extended Data formats | RGB; JPEG preferred, or TIFF or EPS; at most 300 dpi and 10 MB; sized to fit one page with room for the caption |

### Layout and content

| Requirement | Nature's words |
|---|---|
| Simplicity | "as small and simple as is compatible with clarity"; avoid "unnecessary complexity, colouring and excessive detail" |
| Panels | "Figures should not contain more than one panel unless the parts are logically connected"; panels in alphabetical order, laid out neatly and space-efficiently, minimizing white space, each sized by its content |
| Keys | "Where possible, text, including keys to symbols, should be provided in the legend rather than on the figure itself" (formatting guide); keys or keylines in the figure "rather than having colour descriptions in the figure caption" (figure guide) |
| Icons | text labels instead of decorative icons |
| Graphs: required | axis lines and tick marks; axes labeled with units in parentheses; an accessible palette; text of at least 5 pt; standard fonts |
| Graphs: avoided | background gridlines; superfluous icons and decorative elements; drop shadows; patterns; text on busy backgrounds; overlapping text; coloured text ("keylines, keys, etc. should be used instead") |
| Colour references | keylines pointing to black text labels; coloured boxes with black text to refer to a colour |
| Greek letters | Symbol font for glyphs and the Greek alphabet |
| Photographs | at least 300 dpi; 450 dpi or more for the best online proof; scale bars and their text on a separate, editable layer |
| Schematics | no separate specification: they follow the rules for all figures; a simple schematic may go in an Extended Data figure |
| Color | avoid red/green combinations and rainbow scales |

`SKILL.md` reconciles the two key rules: series are labeled directly on the figure, in black (the in-figure key); symbols, values and notes go in the caption (rules 6 and 7).

### Captions (Nature: "figure legends")

| Requirement | Nature's words |
|---|---|
| Length | "Legends should be fewer than 300 words each" |
| Opening | "Each figure legend should begin with a brief title for the whole figure" |
| Content | then "a short description of each panel and the symbols used" |
| Statistics | "All error bars and statistics must be defined in the figure legend" |
| Units | unusual units or abbreviations defined in the caption |
| Methods | no details of methods when the paper has a Methods section |
| Placement | with the figure at initial submission; at final submission, listed one after another in the text document. Extended Data captions are prepared the same way |

### Nature Reviews: conceptual figures (secondary)

Nature's "Guide to designing figures" for Nature Reviews covers conceptual figures in commissioned content (reviews, News & Views), which Nature's art team redraws. It is not a requirement for research papers; `rules/diagrams-flowcharts.md` uses it as secondary guidance for diagrams. Its 8 pt text size is not followed: the research figure guide's 5–7 pt governs.

| Topic | Guidance |
|---|---|
| Hierarchy | key elements most saturated, background elements neutral |
| Flow | logical, top to bottom or left to right; readers look top left first; circular layouts only for circular processes |
| Arrows | one arrow for an action; no multiple arrow weights and styles whose meaning is unclear |
| Clarity | explain all elements in labels or the caption; label the first instance of every object |
| Brevity | a full-page figure of no more than six panels |
| Icons | only to aid understanding and context |
| Figure or table | content that only categorises ideas works better as a list or table |

## Other journals (reference only)

Nature's guidance governs this skill. These requirements are kept for authors who must also meet another journal's rules; where they differ from Nature's, the skill follows Nature.

### Science

Source: Science, "Instructions for preparing an initial manuscript", sections on preparing figures and on typefaces and labels.

| Requirement | Science's words or values |
|---|---|
| Widths | "5.7 cm (2.24 inches or 1 column), 12.1 cm (4.76 inches or 2 columns), or 18.4 cm (7.24 inches or 3 columns)" |
| Typeface | "Use a sans-serif font whenever possible (Helvetica is preferred)" |
| Text size | lettering "a reduced size of about 7 points (2.5 mm) high, and not smaller than 5 points"; "Avoid wide variation in type size within a single figure" |
| Case | "Capitalize only the first letter in a label, not every word" (proper nouns excepted) |
| Axis labels | "the parameter or variable being measured, the units of measure in parentheses, and the scale"; "Scales with large or small numbers should be presented as powers of 10" |
| Panel letters | "capital letters for part labels in multipart figures – A, B, C, etc. These should be 10 pt and bold"; upper left corner; avoid sub-part labels such as C(a) |
| Layout | "Panels should be set close to each other, and common axis labels should not be repeated"; "maximize the space given to presentation of the data. Avoid wasted white space and clutter" |
| Color | "Avoid using red and green together"; "Do not use colors that are similar in hue to identify different parts of a figure"; "Avoid using colored type" |
| Formats | vector files preferred; 300 dpi at initial submission, higher at revision |

### PLOS journals

Source: PLOS, "Figures".

| Requirement | PLOS's words or values |
|---|---|
| Widths | 789–2250 pixels at 300 dpi (6.68–19.05 cm) |
| Height | at most 2625 pixels at 300 dpi (22.23 cm) |
| Typeface and size | "Arial, Times, or Symbol font only in 8-12 point" |
| Formats | TIFF or EPS |
| Resolution | 300–600 dpi |
| File size | under 10 MB |

PLOS lists Arial and not Helvetica.

### Others

- *Freshwater Science*: figures "should not contain a title or text that is duplicated in the figure caption"; sans serif only; sentence case. A rule many journals share with Nature: the caption, not the artwork, carries the title.
- Cell Press: read the current figure guidelines (URL in `rules/references.md`); not quoted here because the page could not be retrieved.
